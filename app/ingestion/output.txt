1. Основы Python
Переменные и типы данных
Переменные в Python используются для хранения данных. Имя переменной 
связывается с определенным значением. Для присваивания используется 
оператор =.
Основные типы данных:

int (целые числа): например, x = 5

float (вещественные числа): например, pi = 3.14

str (строки): например, name = "Alice"

bool (логические значения True/False): например, is_valid = True
Пример кода с переменными разных типов:
# Присваиваем переменным различные значения
age = 30               # int
height = 1.75          # float
name = "Alice"         # str
is_student = False     # bool

print(name, "имеет возраст", age, "лет и рост", height, "м.")  
# Выведет: Alice имеет возраст 30 лет и рост 1.75 м.
Обратите внимание, что тип переменной определяется автоматически на 
основе присвоенного значения (динамическая типизация). Функция print() 
позволяет выводить данные на экран. Тип переменной можно проверить с 
помощью функции type(), например type(age) вернет <class 'int'>.
Арифметические и логические операторы
Арифметические операторы используются для математических 
вычислений:

+ (сложение), - (вычитание)

* (умножение), / (деление)

// (целочисленное деление), % (остаток от деления)

** (возведение в степень)
Логические операторы используются для выражений, результатом которых 
является True или False:

== (равенство), != (неравенство)

> (больше), < (меньше)

>= (больше или равно), <= (меньше или равно)

логические операторы and (и), or (или), not (не)
Пример использования арифметических и логических операторов:
a = 10
b = 3
sum_ab = a + b            # 13
power = a ** b           # 10^3 = 1000
is_greater = a > b       # True, так как 10 > 3
is_between = (5 < a < 15) # True, 10 находится между 5 и 15
print(sum_ab, power, is_greater, is_between)

# Выведет: 13 1000 True True
В примере выше мы вычисляем сумму, возводим число в степень и 
проверяем логические условия. Выражение (5 < a < 15) демонстрирует 
"цепочку" сравнений в Python.
Ввод/вывод
Вывод данных осуществляется функцией print(), как мы уже видели. Она 
может принимать несколько аргументов через запятую и выводить их 
подряд, разделяя пробелами (по умолчанию). Можно изменить разделитель с
помощью параметра sep и окончание строки через end.
Ввод данных от пользователя осуществляется функцией input(). Эта функция 
приостанавливает выполнение программы и ожидает ввода текста, который 
затем возвращает в виде строки.
Пример ввода-вывода:
name = input("Введите ваше имя: ")  # Пользователь вводит свое имя
print("Привет,", name, "!")        # Выводит приветствие
# Пример ввода числа
num_str = input("Введите число: ")
num = int(num_str)  # Преобразуем строку в целое число
print(num, "в квадрате равно", num**2)
В этом примере input() отображает пользователю подсказку (строка "Введите 
ваше имя: "), пользователь вводит текст, и затем программа выводит 
приветствие. Обратите внимание, что input() всегда возвращает строку, 
поэтому для числового ввода мы используем функцию int() для 
преобразования строки в целое число.
Условные конструкции (if, elif, else)
Условные операторы позволяют выполнять код только при выполнении 
определенных условий.


if — проверяет условие, и если оно истинно (True), выполняет блок кода 
под ним.

elif (else if) — добавляет дополнительное условие, которое проверяется, 
если все предыдущие if/elif были ложными.

else — выполняет блок кода, если все вышестоящие условия оказались 
ложными.
Структура условной конструкции:
python
Копировать
x = 10
if x > 0:
    print("x положительное")
elif x < 0:
    print("x отрицательное")
else:
    print("x равно нулю")
Обратите внимание на двоеточия : после условий и на отступы (4 пробела по
PEP8) перед блоками кода. Отступы в Python определяют вложенность блоков 
(что находится внутри if и т.д.). В примере, если x больше 0, выполнится 
только первый print, если меньше 0 — второй, иначе (т.е. x == 0) — третий.
Условные выражения также могут быть записаны в одну строку с помощью 
тернарного оператора:
python
Копировать
result = "положительное" if x > 0 else "не положительное"
Здесь переменной result будет присвоена строка "положительное" если x > 0, 
в противном случае — "не положительное".
Циклы (for, while, range)
Циклы позволяют выполнять блок кода несколько раз.

Цикл for используется для перебора последовательностей (списков, строк, 
диапазонов и т.д.):
python
Копировать
# Выведем все буквы в слове
for char in "Python":
    print(char)
Цикл for последовательно присваивает переменной (char в данном случае) 
элементы последовательности и выполняет тело цикла. В примере будут 
поочередно выведены буквы P, y, t, h, o, n (каждая с новой строки).
Для генерации последовательностей чисел часто используется функция 
range(). Например, range(5) генерирует числа 0,1,2,3,4.
python
Копировать
# Выведем квадраты чисел от 0 до 4
for i in range(5):
    print(i**2)
Цикл while выполняет блок кода, пока условие истинно:
python
Копировать
count = 0
while count < 5:
    print("Count = ", count)
    count += 1  # увеличиваем count, иначе цикл станет бесконечным
Данный цикл начнется с count = 0 и будет выполняться, пока count < 5. В 
каждом повторе мы выводим текущее значение и увеличиваем count на 1. В 
итоге значения 0…4 будут выведены, после чего условие count < 5 станет 
ложным (при count == 5) и цикл завершится.

Операторы управления циклом: внутри циклов можно использовать break 
для досрочного выхода из цикла и continue для перехода к следующей 
итерации, пропуская оставшийся код в цикле текущей итерации.
python
Копировать
for i in range(1, 10):
    if i % 3 == 0:
        continue  # пропускаем вывод чисел, кратных 3
    if i == 8:
        break     # прерываем цикл, когда i равно 8
    print(i, end=" ")
# Вывод: 1 2 4 5 7 
В этом примере число 3 и 6 не будут выведены из-за continue, а цикл 
прервется на i=8 из-за break.
2. Структуры данных и встроенные функции
Python предоставляет несколько встроенных структур данных (коллекций), 
каждая из которых предназначена для своих задач: списки, кортежи, 
множества, словари. Кроме того, язык содержит множество встроенных 
функций и методов для работы с этими структурами: добавление/удаление 
элементов, сортировка, фильтрация и генерация новых коллекций.
Списки (list)
Список — упорядоченная изменяемая коллекция объектов. Элементы 
списков индексируются целыми числами, начиная с 0.
Создание списка:
python
Копировать
empty_list = []              # пустой список
fruits = ["apple", "banana", "cherry"]  # список строк
numbers = [1, 2, 3, 4, 5]    # список чисел
mixed = [1, "two", 3.0]      # смешанный список

Доступ к элементам списка по индексу: fruits[0] вернет "apple", fruits[1] вернет 
"banana", и т.д. Можно использовать отрицательные индексы (-1 последний 
элемент, -2 предпоследний и т.д.).
Списки изменяемы, мы можем добавлять, удалять или изменять элементы:

append(x) – добавить элемент x в конец списка

extend([...]) – расширить список другим списком (добавить все 
элементы)

insert(i, x) – вставить элемент x по индексу i

remove(x) – удалить первый встреченный элемент x

pop(i) – удалить элемент по индексу i (по умолчанию последний) и 
вернуть его

clear() – очистить список

sort() – сортировать список (для изменяемых списков) или sorted(list) для
получения нового отсортированного списка

reverse() – изменить порядок элементов на обратный
Пример работы с методами списка:
python
Копировать
numbers = [5, 2, 8]
numbers.append(3)        # [5, 2, 8, 3]
numbers.sort()           # [2, 3, 5, 8]
numbers.insert(0, 10)    # [10, 2, 3, 5, 8]
numbers.remove(3)        # [10, 2, 5, 8] (удалена первая найденная 3)
last = numbers.pop()     # [10, 2, 5]; last = 8
print(numbers, last)
# Выведет: [10, 2, 5] 8
В примере мы добавили число, отсортировали список, вставили элемент в 
начало, удалили элемент со значением 3 и извлекли последний элемент.

Также можно получать срезы (sublist) списка: numbers[1:3] вернет элементы с 
индексами 1 и 2. Пропущенное начало или конец означает "до конца". 
Например, numbers[:2] — первые два элемента, numbers[2:] — с третьего до 
конца.
Кортежи (tuple)
Кортеж — упорядоченная неизменяемая коллекция. Похож на список, но 
после создания его элементы нельзя изменить (добавить, удалить, заменить).
Кортеж удобно использовать для фиксированных наборов данных.
Создание кортежа:
python
Копировать
empty_tuple = ()                  # пустой кортеж
point = (10, 20)                  # кортеж из двух чисел
person = ("Alice", 30, False)     # кортеж разных типов
single_elem = ("one",)            # кортеж из одного элемента (обязательна 
запятая!)
Доступ к элементам кортежа осуществляется по индексу так же, как и в списке:
point[0] возвращает 10.
Поскольку кортежи неизменяемы, методы добавления/удаления элементов 
для них не доступны. Однако доступны некоторые функции:

len(tuple) — узнать длину кортежа

операторы in/not in для проверки наличия элемента

можно конкатенировать (сложить) кортежи: (1,2) + (3,4) -> (1,2,3,4)

метод count(x) — сколько раз элемент x встречается в кортеже

метод index(x) — индекс первого вхождения x
Кортежи часто используются для возврата нескольких значений из функции 
или для безопасного хранения данных, которые не должны изменяться.
Пример использования кортежей:
python
Копировать

dimensions = (1920, 1080)
width, height = dimensions  # распаковка кортежа в две переменные
print("Ширина:", width, "Высота:", height)
# Выведет: Ширина: 1920 Высота: 1080
Множества (set)
Множество — неупорядоченная коллекция уникальных элементов. В 
множестве автоматически отсеиваются дубликаты, и оно не сохраняет 
порядок элементов.
Создание множества:
python
Копировать
empty_set = set()               # пустое множество
nums = {1, 2, 3, 3, 2}          # множество из {1, 2, 3} (повторы удалятся)
letters = set("hello")          # множество уникальных символов {'h', 'e', 'l', 'o'}
Обратите внимание: для пустого множества нужно использовать set(), так как 
{} создаст пустой словарь.
Основные операции с множествами:

add(x) – добавить элемент

remove(x) – удалить элемент (Ошибка, если элемента нет)

discard(x) – удалить элемент, если он присутствует (без ошибки, если 
нет)

clear() – очистить множество

Операции над множествами: объединение |, пересечение &, разность -,
симметрическая разность ^.
Пример работы с множествами:
python
Копировать
A = {1, 2, 3}
B = {3, 4, 5}

print(A | B)   # Объединение: {1, 2, 3, 4, 5}
print(A & B)   # Пересечение: {3}
print(A - B)   # Разность: {1, 2} (элементы A, не входящие в B)
print(A ^ B)   # Симметрическая разность: {1, 2, 4, 5}
Множества полезны, когда нужно хранить уникальные элементы или 
эффективно проверять принадлежность (x in set работает быстрее, чем в 
списке при больших наборах данных).
Словари (dict)
Словарь — неупорядоченная коллекция пар "ключ: значение". Ключами 
могут быть неизменяемые типы (числа, строки, кортежи), а значениями — 
любые типы данных. Словари очень полезны для хранения соответствий и 
быстрых поисков по ключу.
Создание словаря:
python
Копировать
empty_dict = {}  # пустой словарь
person = {"name": "Alice", "age": 30}
# альтернатива через функцию dict():
person2 = dict(name="Bob", age=25)
Доступ к значению по ключу: person["name"] вернет "Alice". Если обратиться 
по несуществующему ключу, будет ошибка KeyError. Безопасно получать 
значение можно методом get: person.get("name") (вернет значение или None, 
если ключ не найден).
Основные операции и методы словарей:

Добавление/изменение: dict[key] = value

Удаление: dict.pop(key) (удалить и вернуть значение) или del dict[key]

Получение всех ключей: dict.keys()

Получение всех значений: dict.values()

Получение всех пар ключ-значение: dict.items() (удобно для перебора в 
цикле)


Метод update(other_dict) — обновить словарь элементами из другого 
словаря.

Проверка наличия ключа: оператор in проверяет наличие ключа в 
словаре.
Пример работы со словарём:
python
Копировать
student = {"name": "John", "grades": [5, 4, 5]}
student["age"] = 20              # добавляем новый ключ-значение
student["name"] = "Johnny"       # изменяем значение по существующему ключу
for key, value in student.items():
    print(key, ":", value)
# Выведет:
# name : Johnny
# grades : [5, 4, 5]
# age : 20
student.pop("age")               # удаляем ключ "age"
print(student.get("age"))        # безопасно пытаемся получить удаленный ключ 
(None)
В цикле мы перебрали словарь, используя items() для получения пары ключ-
значение. После удаления ключа "age", метод get вернул None (т.к. ключа 
больше нет, вместо ошибки).
Методы для работы с коллекциями
(Приведенные выше методы относятся к своим коллекциям. Далее – сводная 
информация и некоторые дополнительные встроенные функции для всех 
коллекций.)

len(seq) – размер (число элементов) в коллекции. Работает для списков, 
кортежей, множеств, словарей (в случае словаря – количество ключей).


min(seq), max(seq) – минимальный/максимальный элемент коллекции 
(элементы должны быть сравнимы между собой).

sum(seq) – сумма элементов (для числовых коллекций).

sorted(seq) – возвращает новый отсортированный список из элементов
коллекции (исходная коллекция не изменяется).

reversed(seq) – возвращает итератор для обхода последовательности в 
обратном порядке. Например, list(reversed([1,2,3])) даст [3,2,1].

enumerate(seq) – возвращает итератор, генерирующий пары (индекс, 
значение) для списка или другого итерируемого объекта. Удобно при 
переборе в цикле:
python
Копировать
for index, value in enumerate(["a", "b", "c"]):
    print(index, "->", value)
# Выведет:
# 0 -> a
# 1 -> b
# 2 -> c

zip(seq1, seq2, ...) – возвращает итератор, порождающий кортежи из 
элементов переданных коллекций. Полезно для параллельного 
перебора. Например:
python
Копировать
names = ["Anna", "Bob"]
ages = [25, 30]
for name, age in zip(names, ages):
    print(name, "is", age, "years old")
# Выведет:
# Anna is 25 years old

# Bob is 30 years old
Сортировка и фильтрация
Python предлагает удобные способы сортировки и фильтрации коллекций.
Сортировка:

Метод списка list.sort() сортирует список на месте (изменяет его) и 
ничего не возвращает.

Функция sorted(iterable) возвращает новый отсортированный список из 
любого итерируемого объекта (списка, кортежа и т.д.), оставляя 
исходный без изменений.
Оба метода поддерживают параметры:

reverse=True для сортировки в обратном порядке (убывание).

key=function для сортировки по ключу (например, длине строки: 
key=len).
Пример сортировки:
python
Копировать
numbers = [5, 2, 9, 1]
sorted_numbers = sorted(numbers)         # [1, 2, 5, 9]
sorted_numbers_desc = sorted(numbers, reverse=True)  # [9, 5, 2, 1]
words = ["python", "java", "c++", "swift"]
words.sort(key=len)  # сортируем список слов на месте по длине слова
print(words)         # ['c++', 'java', 'swift', 'python']
Здесь words.sort(key=len) отсортировал список строк по возрастанию их 
длины.
Фильтрация:
Фильтровать последовательности можно разными способами:

С помощью условного выражения в цикле (императивно).


С помощью встроенной функции filter(function, iterable), которая 
оставляет только элементы, для которых function(element) возвращает 
True.

С помощью генераторов списков (list comprehensions) с условием.
Например, выберем из списка чисел только четные:
python
Копировать
numbers = [1, 2, 3, 4, 5, 6]
evens1 = [x for x in numbers if x % 2 == 0]              # [2, 4, 6]
# То же самое с функцией filter и лямбда-функцией:
evens2 = list(filter(lambda x: x % 2 == 0, numbers))     # [2, 4, 6]
Оба способа дают одинаковый результат – список четных чис. Первый 
вариант с генератором списков часто более читаем.
Генераторы списков (List comprehensions)
Генераторы списков – краткий способ создать новый список, применяя 
выражение к каждому элементу последовательности (и, возможно, фильтруя 
элементы по условию). Синтаксис: [<выражение> for <элемент> in <итерация> 
if <условие>]. Условие опционально.
Примеры генераторов списков:
python
Копировать
# Создать список квадратов чисел от 0 до 9
squares = [x*x for x in range(10)]  
# squares = [0, 1, 4, 9, ..., 81]
# Создать список из строк длиннее 3 символов, приведя их к верхнему 
регистру
words = ["cat", "penguin", "dog", "elephant"]
long_words_upper = [w.upper() for w in words if len(w) > 3]

# long_words_upper = ["PENGUIN", "ELEPHANT"]
Генераторы списков делают код более компактным и читаемым. Аналогично 
существуют генераторы множеств и генераторы словарей, использующие 
схожий синтаксис с фигурными скобками {}. Например:
python
Копировать
nums = [1, 2, 3, 2, 1]
unique_squares = {x*x for x in nums}  
# unique_squares = {1, 4, 9}  (множество уникальных квадратов)
3. Функции
Функции позволяют объединить повторяющийся или логически связанный 
код в единый блок, которому можно давать имя и вызывать его по 
необходимости. Они помогают структурировать программу и избегать 
дублирования.
Объявление и вызов функций
Для объявления функции используется ключевое слово def, за которым 
следует имя функции, круглые скобки с параметрами (если есть) и двоеточие. 
Тело функции определяется отступом. Чтобы функция что-то вернула, 
используется оператор return. Если return не указан, функция возвращает 
None по умолчанию.
Пример функции:
python
Копировать
def greet(name):
    """Приветствует пользователя по имени."""  # строка документации 
функции (docstring)
    greeting = f"Hello, {name}!"
    return greeting
# Вызов функции

message = greet("Alice")
print(message)  # Выведет: Hello, Alice!
Здесь мы определили функцию greet с одним параметром name. Она 
возвращает приветственное сообщение. Строка в тройных кавычках сразу 
после объявления — это документационная строка (docstring), описывающая 
функцию.
Функцию можно вызывать многократно с разными аргументами:
python
Копировать
print(greet("Bob"))    # Hello, Bob!
print(greet("Charlie"))  # Hello, Charlie!
Аргументы функций (позиционные, именованные, *args, **kwargs)
При определении функции можно указать параметры, а при вызове — 
передать аргументы.
Позиционные аргументы передаются по порядку:
python
Копировать
def add(a, b):
    return a + b
print(add(3, 4))  # 7 (3 и 4 переданы как позиционные аргументы a и b)
Именованные аргументы указываются при вызове по имени параметра:
python
Копировать
print(add(b=4, a=3))  # 7 (порядок неважен, так как указаны имена)
Можно комбинировать позиционные и именованные аргументы, но 
позиционные должны идти до именованных.

Аргументы по умолчанию: при объявлении функции можно задать 
значение по умолчанию для параметра. Тогда этот параметр необязателен 
при вызове:
python
Копировать
def greet(name, greeting="Hello"):
    print(greeting, name)
greet("Alice")                # Hello Alice  (использовано значение по умолчанию)
greet("Bob", greeting="Hi")   # Hi Bob       (переопределено значение по 
умолчанию)
Произвольное количество аргументов:

*args позволяет функции принимать любое количество позиционных 
аргументов (внутри функции они будут доступны как кортеж).

**kwargs позволяет принимать любое количество именованных 
аргументов (внутри функции они будут в виде словаря).
Пример с *args и **kwargs:
python
Копировать
def process(*args, **kwargs):
    # args - кортеж позиционных аргументов
    # kwargs - словарь именованных аргументов
    print("Positional:", args)
    print("Named:", kwargs)
process(1, 2, 3, name="Alice", age=30)
# Выведет:
# Positional: (1, 2, 3)
# Named: {'name': 'Alice', 'age': 30}

Вызов process(1, 2, 3, name="Alice", age=30) передал 3 позиционных аргумента 
и 2 именованных, которые внутри функции доступны через args и kwargs.
Распаковка аргументов: Если у вас есть последовательность или словарь, их
можно "распаковать" при вызове функции с помощью * и **:
python
Копировать
nums = [5, 7]
print(add(*nums))  # то же что add(5, 7), распакует список в два аргумента
params = {"name": "Charlie", "greeting": "Hi"}
greet(**params)    # то же что greet(name="Charlie", greeting="Hi")
Область видимости и замыкания
Область видимости (scope) – контекст, в котором определены переменные. 
В Python есть локальная область видимости (внутри функции) и глобальная 
(на уровне модуля/скрипта). Переменная, созданная внутри функции, не 
видна снаружи (локальная переменная). Глобальные переменные доступны 
внутри функций, но чтобы изменить глобальную переменную внутри 
функции, нужно объявить ее как global.
Пример областей видимости:
python
Копировать
x = 10  # глобальная переменная
def foo():
    x = 5  # локальная переменная (другая, не меняет глобальную)
    print("Inside foo, x =", x)
foo()
print("Global x =", x)

# Выведет:
# Inside foo, x = 5
# Global x = 10
В примере значение глобального x не изменилось после вызова foo(), так как 
внутри функции мы работали с локальной переменной x. Если нужно внутри 
функции изменить глобальную x, объявляем global x внутри функции, а затем
присваиваем ей новое значение.
Замыкание (closure) – функция, которая "запоминает" значения переменных
из внешней области видимости, даже если та уже недоступна. Замыкания 
возникают, когда внутренняя функция ссылается на переменные, 
определенные во внешней (но не глобальной) функции, и внешняя функция 
возвращает внутреннюю функцию.
Пример замыкания:
python
Копировать
def make_multiplier(factor):
    def multiply(x):
        return x * factor
    return multiply
double = make_multiplier(2)
triple = make_multiplier(3)
print(double(5))  # 10
print(triple(5))  # 15
В данном случае make_multiplier создает и возвращает функцию multiply, 
которая помнит значение factor из внешней функции. Функция double хранит
внутри себя factor = 2, а triple — factor = 3. Несмотря на то, что выполнение 
make_multiplier завершилось, переменная factor "замкнута" внутри функции 
multiply.

4. Модули и пакеты
По мере роста программы, становится неудобно хранить весь код в одном 
файле. Модули и пакеты помогают организовывать код, разделяя его на 
логические части и позволяя повторно использовать. Модуль в Python — это 
просто файл с расширением .py, содержащий какой-то код (функции, классы, 
переменные). Пакет — это директория с набором модулей, содержащая файл 
__init__.py (может быть пустым) для указания, что данная директория является 
пакетом.
Импорт встроенных и внешних модулей
Python имеет множество встроенных модулей (стандартная библиотека), 
которые можно использовать сразу. Чтобы использовать код из модуля, его 
нужно импортировать.
Синтаксис импорта:
python
Копировать
import module_name         # импорт модуля целиком
module_name.some_function()
from module_name import some_function, SomeClass  # выборочный импорт 
объектов
some_function()
Примеры:
python
Копировать
import math
print(math.sqrt(16))       # Выведет: 4.0
from random import randint
print(randint(1, 10))      # Выведет случайное число от 1 до 10 (включительно)

Можно задавать псевдонимы для модулей или функций, чтобы сократить 
имя:
python
Копировать
import math as m
print(m.pi)                # 3.14159...
from datetime import datetime as dt
print(dt.now())            # текущие дата и время
Внешние модули – это модули, не входящие в стандартную библиотеку, 
написанные сторонними разработчиками. Перед использованием их нужно 
установить (с помощью менеджера пакетов pip). Пример популярного 
внешнего модуля – requests для выполнения HTTP-запросов (о нём подробнее
в разделе 9).
Создание собственных модулей
Вы можете создавать свои модули. Например, если у вас есть файл utils.py с 
несколькими функциями, вы можете импортировать их в другом файле:
python
Копировать
# utils.py
def hello(name):
    print(f"Hello, {name}!")
# main.py
import utils
utils.hello("Alice")   # Выведет: Hello, Alice!
Важно, чтобы файлы модулей находились либо в той же директории, либо в 
одной из директорий, указанных в sys.path (пути поиска модулей). Также 
можно организовывать модули по папкам (пакетам). Например, создадим 
пакет math_utils:

markdown
Копировать
math_utils/
    __init__.py        (можно оставить пустым или выполнить некоторую 
инициализацию)
    geometry.py        (например, функции для расчёта площади, периметра)
    algebra.py         (например, функции для решения уравнений)
Использование:
python
Копировать
from math_utils import geometry
from math_utils.algebra import solve_equation  # предположим, есть такая 
функция
Работа с виртуальными окружениями (virtualenv) и установкой пакетов 
(pip)
При работе над проектами на Python часто используют виртуальные 
окружения. Виртуальное окружение — это изолированная среда, в которой 
установлены только необходимые для проекта пакеты, не влияющие на 
систему в целом. Это помогает избежать конфликтов версий разных 
проектов.
Создание и активация виртуального окружения:

В Python 3 стандартный модуль venv позволяет создавать окружения.
bash
Копировать
# В командной строке
python3 -m venv venv        # создание виртуального окружения в папке ./venv
source venv/bin/activate    # активация окружения на Mac/Linux
venv\Scripts\activate       # активация на Windows

После активации в командной строке будет отображаться имя окружения 
(например, (venv)), и вызов python/pip будет относиться к окружению.
Установка пакетов выполняется через менеджер пакетов pip. Например:
nginx
Копировать
pip install requests        # устанавливаем внешний пакет requests
pip install django==3.2     # устанавливаем конкретную версию пакета django
pip install -r requirements.txt  # устанавливаем все пакеты, перечисленные в 
файле
Файл requirements.txt обычно содержит список зависимостей проекта. Его

После установки пакета в виртуальном окружении, вы можете импортировать
его в вашем Python-коде как обычный модуль. Например, после pip install 
requests вы можете написать import requests в своем скрипте.
Виртуальные окружения можно деактивировать командой deactivate.
5. Работа с файлами
Работа с файлами — важная часть программирования. Python позволяет 
легко читать и записывать файлы на диске. Основной функцией для работы с 
файлами является open(), которая возвращает объект файла.
Чтение и запись файлов (режимы 'r', 'w', 'a')
Функция open(filename, mode) открывает файл и возвращает файловый 
объект. Режим (mode) определяет, что мы собираемся делать:

'r' – чтение (read, файл должен существовать)

'w' – запись (write, файл создается заново или очищается если уже 
существовал)

'a' – добавление (append, записывать в конец существующего файла)

'r+' – чтение и запись одновременно

Также есть режимы бинарного чтения/записи 'rb', 'wb' и т.д. для 
двоичных файлов (изображения, аудио и др.)

Простейший пример записи текста в файл:
python
Копировать
file = open("example.txt", "w")  # открываем файл для записи 
(создается/очищается)
file.write("Hello, file!\n")     # записываем строку (нужно явно добавить перевод 
строки \n)
file.write("Second line\n")     
file.close()                     # закрываем файл, чтобы сохранить изменения
Важно закрывать файл после работы (методом close()), чтобы данные точно 
записались на диск и освободились ресурсы. Если файл не закрыть, запись 
может не завершиться корректно.
Чтение из файла:
python
Копировать
file = open("example.txt", "r")
content = file.read()        # читаем всё содержимое файла в одну строку
print(content)
file.close()
Методы чтения:

file.read(n) – прочитать n символов (или байт в бинарном режиме). Без 
аргументов – весь файл.

file.readline() – прочитать одну строку (до \n).

file.readlines() – прочитать все строки и вернуть списком строк.
Запись:

file.write(string) – записать строку (или данные байтов в бинарном 
режиме).

file.writelines(list_of_strings) – записать список строк подряд.
Контекстный менеджер with open(...)

Чтобы не забывать закрывать файл вручную, часто используют конструкцию 
with, которая автоматически закрывает файл по завершении блока:
python
Копировать
with open("example.txt", "r") as file:
    for line in file:
        print(line.strip())
# файл автоматически закрыт после выхода из блока with
В этом примере файл открыт в режиме чтения, и мы итерируемся по нему 
построчно (сам файловый объект является итератором по строкам). Метод 
strip() убирает символы переноса строк. После выхода из блока with файл 
закрывается автоматически, даже если внутри блока произошло исключение.
Запись с помощью with:
python
Копировать
with open("output.txt", "a") as file:   # открываем на добавление
    file.write("New line\n")
# файл закрыт автоматически
6. Исключения
Исключения используются для обработки ошибок и неожиданных ситуаций 
в коде. Вместо аварийного завершения программы при возникновении 
ошибки, мы можем "поймать" исключение и обработать его, позволив 
программе продолжить работу или завершиться корректно.
Конструкции try/except/else/finally
Базовый синтаксис обработки исключений:
python
Копировать
try:
    # блок кода, в котором может возникнуть исключение

    x = int(input("Введите число: "))
    result = 10 / x
except ValueError:
    # этот блок выполнится, если в try возникло ValueError (например, ввод не 
числа)
    print("Вы ввели не число!")
except ZeroDivisionError:
    # выполнится, если возникло деление на ноль
    print("Деление на ноль!")
else:
    # выполнится, если исключений НЕ произошло
    print("Результат:", result)
finally:
    # выполнится в любом случае, произошла ошибка или нет
    print("Спасибо, что используете нашу программу!")
В этом примере:

Блок try содержит код, который может вызвать исключения (int() может 
выбросить ValueError, 10/x – ZeroDivisionError).

Блоки except проверяются по порядку: если в try произошло 
исключение соответствующего типа, выполняется соответствующий 
блок except. Можно перехватывать различные типы исключений, как 
показано.

Блок else выполняется, если никаких исключений в try не возникло (то 
есть, если мы не попали в except).

Блок finally выполняется всегда. Обычно используется для 
завершающих действий (закрытие ресурсов, файлов, соединений), 
которые должны произойти в любом случае.
Важно: Если исключение произошло, но не было перехвачено ни одним 
подходящим except, оно пробрасывается дальше и, если не обработается 
нигде, приводит к падению программы с сообщением об ошибке (traceback).

Создание собственных исключений
Иногда полезно самим возбуждать (генерировать) исключения, если 
происходят нежелательные ситуации, или создавать новые типы исключений
для своей библиотеки.
Генерация исключения: используется ключевое слово raise. Например:
python
Копировать
def set_age(age):
    if age < 0:
        raise ValueError("Возраст не может быть отрицательным!")
    print("Возраст установлен:", age)
set_age(-5)  
# Возбудит исключение ValueError: Возраст не может быть отрицательным!
Здесь мы явно выбрасываем ValueError с собственным сообщением, если 
входной аргумент не подходит.
Собственные типы исключений: Можно создавать классы исключений, 
наследуя их от встроенных. Обычно наследуют от Exception или от какого-то 
специализированного подкласса. Например:
python
Копировать
class NegativeAgeError(Exception):
    """Ошибка: отрицательный возраст."""
    pass
def set_age(age):
    if age < 0:
        raise NegativeAgeError("Возраст не может быть отрицательным!")

Теперь, если вызвать set_age(-5), возникнет исключение типа 
NegativeAgeError. Его можно ловить в блоке try/except так же, как 
стандартные:
python
Копировать
try:
    set_age(-5)
except NegativeAgeError as e:
    print("Ошибка:", e)
Создание собственных исключений полезно в крупных проектах, чтобы более
точно сообщать об ошибках. Название класса исключения должно отражать 
суть проблемы.
7. Объектно-ориентированное программирование (OOP)
Объектно-ориентированное программирование позволяет моделировать 
сущности из реального мира в виде классов и объектов. Класс описывает 
общую структуру (свойства и поведение), а объект является конкретным 
экземпляром класса.
Классы, атрибуты и методы
Класс объявляется ключевым словом class. Внутри класса можно определять 
атрибуты (переменные, связанные с объектами или классом) и методы 
(функции, выполняющие действия, связанные с объектом).
Пример определения класса и создания объекта:
python
Копировать
class Person:
    species = "Homo sapiens"  # атрибут класса (общий для всех экземпляров)
    
    def __init__(self, name, age):
        # метод-конструктор, вызывается при создании объекта
        self.name = name      # атрибут экземпляра

        self.age = age        # атрибут экземпляра
    
    def say_hello(self):
        # метод экземпляра, использует атрибуты объекта через self
        print(f"Hello, my name is {self.name}. I am {self.age} years old.")
# Создание объектов (экземпляров класса Person)
person1 = Person("Alice", 30)
person2 = Person("Bob", 25)
# Использование атрибутов и методов
print(person1.name)         # Alice
person2.say_hello()         # Выведет: Hello, my name is Bob. I am 25 years old.
print(Person.species)       # Homo sapiens (доступ к атрибуту класса)
В данном примере:

species – атрибут класса Person. Доступен как через объект (например, 
person1.species), так и через сам класс Person.species.

Метод __init__ – это специальный метод-конструктор, который 
вызывается при создании нового объекта класса. Он задает атрибуты 
экземпляра (self.name, self.age).

Ключевое слово self в методах класса ссылается на конкретный 
экземпляр объекта, с которым производится работа. Через self мы 
обращаемся к атрибутам и другим методам объекта.

say_hello – обычный метод экземпляра, который выводит приветствие, 
используя данные объекта.
Атрибуты могут быть как у экземпляра (у каждого объекта свои значения, как
name и age), так и у класса (общие для всех объектов, как species). Также 
возможны приватные (условно) атрибуты, которым по соглашению дают 
имена с одним или двумя подчеркиваниями (например, _hidden или 
__very_hidden), чтобы указать, что это служебная переменная. Полностью 

приватных атрибутов в Python нет (все атрибуты доступны извне, если знать 
их имя), но соглашения помогают поддерживать код.
Конструктор __init__
Как показано выше, __init__ – это метод, который вызывается автоматически 
при создании нового объекта класса (Person("Alice", 30) вызывает 
Person.__init__(self, "Alice", 30)). В __init__ обычно прописывают начальную 
инициализацию объекта.
Другие магические методы (они же специальные методы) начинаются и 
заканчиваются двумя подчеркиваниями. Некоторые распространенные:

__str__(self) – метод, определяющий строковое представление объекта 
(что выведется при print(obj)).

__repr__(self) – представление объекта для разработчика (в 
интерактивной среде или через repr()).

__eq__(self, other) – метод для определения поведения оператора == 
(сравнение объектов).

__len__(self) – возвращает размер объекта (делает объект совместимым 
с len()).

и многие другие (add, iter, getitem и т.д. для перегрузки операций).
Наследование, полиморфизм и инкапсуляция
Наследование позволяет описать новый класс на основе существующего, 
перенимая его свойства и поведение. Новый класс называется производным
(класс-наследник), а исходный – базовым (родительским). Наследование 
помогает повторно использовать код и создавать иерархии классов.
Пример наследования:
python
Копировать
class Animal:
    def __init__(self, name):
        self.name = name
    def speak(self):
        print(f"{self.name} издает звук.")

class Dog(Animal):  # класс Dog наследует от Animal
    def speak(self):
        print(f"{self.name} лает: Гав!")
class Cat(Animal):  # класс Cat наследует от Animal
    def speak(self):
        print(f"{self.name} мяукает: Мяу!")
dog = Dog("Бобик")
cat = Cat("Мурка")
dog.speak()  # Бобик лает: Гав!
cat.speak()  # Мурка мяукает: Мяу!
Здесь класс Animal является базовым, а Dog и Cat унаследовали атрибут name 
и метод speak. Они переопределили метод speak под свой звук. Объекты Dog 
и Cat можно использовать там, где ожидается Animal (это и есть проявление 
полиморфизма).
Полиморфизм – способность объектов разных классов иметь одинаковый 
интерфейс (набор методов). В примере выше и Dog, и Cat имеют метод speak, 
поэтому с ними можно обращаться единообразно:
python
Копировать
animals = [Dog("Пёс"), Cat("Кот")]
for animal in animals:
    animal.speak()  # для каждого вызовется своя реализация speak
Полиморфизм часто выражается фразой "один интерфейс – много 
реализаций".
Инкапсуляция – сокрытие внутренних деталей реализации класса и 
предоставление внешнего интерфейса для взаимодействия. В Python нет 

строгой приватности, но есть соглашения: атрибут, начинающийся с _, 
считается внутренним и не предназначен для внешнего использования. 
Инкапсуляция позволяет изменять внутреннюю реализацию, не влияя на 
внешний код, который пользуется классом. Например, класс может хранить 
данные в одном формате, но предоставлять методы для доступа/изменения 
этих данных. В дальнейшем можно изменить способ хранения, оставив 
методы прежними – внешний код не пострадает.
8. Полезные стандартные модули
Стандартная библиотека Python очень богата. Рассмотрим несколько часто 
используемых модулей и примеры задач, которые они решают:
datetime
Модуль datetime предоставляет классы для работы с датами и временем.
Пример: получить текущую дату и время, вычислить разницу между датами:
python
Копировать
from datetime import datetime, timedelta
now = datetime.now()
print("Сейчас:", now)  # текущие дата и время
# Создать дату вручную
new_year = datetime(2025, 1, 1, 0, 0, 0)
diff = new_year - now
print("До нового года дней:", diff.days)
Класс timedelta (как в примере diff) представляет разницу между двумя 
моментами времени. В модуле также есть класс date (только дата), time 
(только время), datetime (комбинированно), функции для форматирования и 
разбора дат (методы strftime и strptime).
os
Модуль os предоставляет функции для взаимодействия с операционной 
системой: работать с файловой системой, путями, переменными окружения, 

процессами.
Пример:
python
Копировать
import os
current_dir = os.getcwd()            # получить текущую рабочую директорию
files = os.listdir(current_dir)      # список файлов в директории
os.mkdir("new_folder")               # создать новую папку
os.rename("new_folder", "renamed_folder")  # переименовать папку
os.rmdir("renamed_folder")           # удалить пустую папку
Модуль os.path содержит функции для работы с путями (соединение, 
разделение расширения, проверка существования и т.д.). Например:
python
Копировать
import os
file_path = "/path/to/file.txt"
print(os.path.basename(file_path))   # "file.txt"
print(os.path.dirname(file_path))    # "/path/to"
print(os.path.exists(file_path))     # проверка существования файла (True/False)
sys
Модуль sys предоставляет доступ к некоторым переменным и функциям, 
связанным с интерпретатором Python.
Пример использования:
python
Копировать
import sys

print(sys.argv)    # список аргументов командной строки, переданных скрипту
print(sys.platform) # название платформы (например, "win32", "linux")
sys.exit(0)         # завершение программы с кодом выхода 0 (успех)
Через sys.argv можно получать входные параметры, переданные скрипту при 
запуске из терминала. Например, если вызвать python script.py arg1 arg2, то 
sys.argv будет ["script.py", "arg1", "arg2"].
random
Модуль random используется для генерации случайных чисел и случайного 
выбора.
Некоторые функции модуля:

random.random() – случайное число от 0.0 до 1.0

random.randint(a, b) – случайное целое число N в диапазоне [a, b]

random.choice(seq) – случайный элемент из последовательности

random.shuffle(seq) – перемешать список на месте

random.sample(seq, k) – список из k уникальных элементов, случайно 
выбранных из последовательности
Пример:
python
Копировать
import random
print(random.random())        # например, 0.634...
print(random.randint(1, 6))   # имитация броска кубика (1-6)
choices = ["red", "green", "blue"]
print(random.choice(choices)) # случайно выберет один из цветов
cards = [1,2,3,4,5]
random.shuffle(cards)
print(cards)                  # список перемешан случайным образом

Для воспроизводимости случайных результатов можно установить seed 
генератора через random.seed(x) с некоторым фиксированным числом.
math
Модуль math содержит множество математических функций: тригонометрия, 
логарифмы, факториал, константы (π, e), и т.д.
Пример:
python
Копировать
import math
print(math.pi)          # 3.14159...
print(math.sqrt(25))    # 5.0, квадратный корень
print(math.factorial(5))# 120, факториал 5
print(math.sin(math.radians(30)))  # синус 30 градусов (math.radians переводит в
радианы)
Если нужна произвольная точность вычислений или работа с дробями, есть 
модули decimal (для десятичных дробей с заданной точностью) и fractions (для
рациональных чис).
collections
Модуль collections предоставляет дополнительные структуры данных:

deque (двунаправленная очередь) – эффективные операции 
добавления/удаления с обоих концов.

Counter – счетчик для подсчета количества элементов 
(мультимножество).

OrderedDict – словарь, помнящий порядок добавления ключей (в Python
3.7+ обычный dict уже сохраняет порядок).

defaultdict – словарь с значением по умолчанию для несуществующих 
ключей.

namedtuple – быстросоздаваемый класс-структура с именованными 
полями.

Примеры:
python
Копировать
from collections import deque, Counter
# deque как очередь FIFO
queue = deque()
queue.append("task1")
queue.append("task2")
print(queue.popleft())  # 'task1' (удаляем первый элемент)
# Counter для подсчета частоты элементов
chars = Counter("hello world")
print(chars)            # Counter({'l': 3, 'o': 2, 'h': 1, 'e': 1, ' ': 1, 'w': 1, 'r': 1, 'd': 1})
print(chars['l'])       # 3 (буква 'l' встречается 3 раза)
defaultdict позволяет задавать тип для значения по умолчанию. Например:
python
Копировать
from collections import defaultdict
d = defaultdict(int)    # значение по умолчанию 0 для новых ключей
print(d["unknown"])     # 0, вместо KeyError
d["unknown"] += 5
print(d["unknown"])     # 5
9. Работа с API и JSON
Современные приложения часто обмениваются данными через API 
(Application Programming Interface). Часто это веб-сервисы, которые 
принимают и возвращают данные в формате JSON (JavaScript Object Notation).

Рассмотрим, как в Python выполнять HTTP-запросы и работать с форматом 
JSON.
HTTP-запросы с библиотекой requests
Библиотека requests (не входит в стандартную библиотеку, устанавливается 
отдельно) значительно упрощает выполнение HTTP-запросов по сравнению с
встроенным модулем urllib. С помощью requests можно легко делать запросы 
GET, POST и другие.
Пример GET-запроса:
python
Копировать
import requests
response = requests.get("https://api.github.com")  # выполнить GET-запрос
print(response.status_code)   # например, 200
print(response.headers["content-type"])  # тип содержимого ответа
print(response.text[:100])    # первые 100 символов тела ответа (в виде текста)
Метод requests.get() возвращает объект Response, содержащий:

status_code – код статуса HTTP (200, 404, 500, etc.)

headers – заголовки ответа

text – тело ответа как строку (если это текст)

json() – метод, пытающийся преобразовать JSON-ответ сразу в объекты 
Python (словарь/список)
Пример POST-запроса (например, отправка JSON на сервер):
python
Копировать
url = "https://httpbin.org/post"
data = {"name": "Alice", "age": 30}
response = requests.post(url, json=data)  # отправляем POST с JSON данными
print(response.status_code)   # 200

print(response.json())        # получаем ответ сервера как словарь (httpbin 
отражает назад то, что получили)
В requests.post, если указать параметр json=data, библиотека сама 
сериализует словарь data в JSON и установит заголовок Content-Type: 
application/json. Аналогично, requests.get может принимать параметр params 
для передачи GET-параметров.
Загрузка и отправка данных
Часто API требуют отправки данных (например, заполнение и отправка 
форм).

Для GET-запросов данные передаются как параметры URL. В 
requests.get(url, params={"q": "test"}) вы можете передать словарь 
параметров, и библиотека сама закодирует их, добавив к URL 
(например, ?q=test).

Для POST/PUT запросов данные могут передаваться как форма 
(data={"field": "value"}) либо как JSON (json={"key": "value"}).

Также через files параметр можно отправлять файлы (например, 
files={"file": open("report.pdf", "rb")}).
Получение данных:

У объекта Response метод .content возвращает сырые данные в виде 
байтов (полезно для загрузки файлов, изображений).

Метод .iter_content() позволяет загружать большой ответ по частям.
Пример загрузки файла из интернета:
python
Копировать
url = "https://example.com/image.png"
response = requests.get(url)
if response.status_code == 200:
    with open("image.png", "wb") as f:
        f.write(response.content)
Здесь мы записали содержимое ответа (байты) в файл image.png.

Формат JSON (сериализация и десериализация)
JSON (JavaScript Object Notation) – формат обмена данными, основанный на 
записи объектов JavaScript. Он широко используется благодаря простоте и 
читаемости. В Python есть встроенный модуль json для работы с этим 
форматом.
Сериализация – преобразование объекта Python (словаря, списка и т.д.) в 
строку JSON.
Десериализация – обратный процесс: JSON-строка -> объект Python.
Пример:
python
Копировать
import json
# Допустим, у нас есть словарь (Python-объект)
person = {"name": "Alice", "age": 30, "is_student": False, "languages": ["English", 
"Spanish"]}
# Сериализация: словарь -> JSON-строка
json_str = json.dumps(person)
print(json_str)  
# Выведет строку в формате JSON, например: 
# {"name": "Alice", "age": 30, "is_student": false, "languages": ["English", "Spanish"]}
# Десериализация: JSON-строка -> словарь
data = json.loads(json_str)
print(data["name"])  # Alice
Функция json.dumps(obj) превращает объект в строку JSON. Часто 
используется параметр ensure_ascii=False для корректного вывода Unicode-
символов (например, русских букв) и параметр indent=4 для красивого 
форматирования с отступами.

Соответственно, json.loads(str) парсит JSON-строку в объект (обычно словарь 
или список).
При работе с файлами JSON удобно использовать json.dump(obj, file) и 
json.load(file) для записи и чтения непосредственно из файлов:
python
Копировать
# Запись JSON в файл
with open("data.json", "w", encoding="utf-8") as f:
    json.dump(person, f, ensure_ascii=False, indent=4)
# Чтение JSON из файла
with open("data.json", "r", encoding="utf-8") as f:
    data_from_file = json.load(f)
В комбинации с requests, часто делают так:
python
Копировать
response = requests.get("https://api.github.com")
data = response.json()  # сразу получаем Python-словарь из JSON ответа
Метод .json() под капотом делает json.loads для response.text. Нужно быть 
уверенным, что ответ действительно в формате JSON, иначе будет ошибка.
10. Работа с базами данных
Хранение данных в файлах подходит не всегда. Когда данные 
структурированы и их много, используют базы данных (БД). Python 
предоставляет как низкоуровневые средства взаимодействия с БД (например,
модуль sqlite3), так и более высокоуровневые, как ORM (Object-Relational 
Mapping) библиотеки, например SQLAlchemy.
SQLite3 (встроенная база данных) и выполнение SQL-запросов
SQLite – легковесная встроенная база данных, которая хранится в одном 
файле на диске. Python включает модуль sqlite3 для работы с SQLite.

Основы работы с SQLite:
1. Подключиться к базе (если файла базы нет, он будет создан).
2. Создать "курсор" для выполнения запросов.
3. Выполнять SQL-запросы (создание таблиц, добавление, выборка 
данных и т.д.).
4. Закрыть соединение.
Пример создания таблицы и вставки данных:
python
Копировать
import sqlite3
# Соединяемся с базой данных (файл example.db в текущей директории)
conn = sqlite3.connect("example.db")
cursor = conn.cursor()
# Создаем таблицу пользователей (если не существует)
cursor.execute("""
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY,
    name TEXT,
    age INTEGER
)
""")
# Вставляем запись в таблицу
cursor.execute("INSERT INTO users (name, age) VALUES (?, ?)", ("Alice", 30))
conn.commit()  # сохраняем изменения (commit транзакции)

# Получаем данные
cursor.execute("SELECT * FROM users")
rows = cursor.fetchall()
print(rows)  # например, [(1, 'Alice', 30)]
# Закрываем соединение
conn.close()
Обратите внимание:

Используется ? как placeholder для параметров в запросе, а сами 
значения передаются вторым аргументом execute. Это защищает от 
SQL-инъекций.

После операций изменения данных (INSERT/UPDATE/DELETE) нужно 
вызвать conn.commit(), чтобы сохранить изменения.

cursor.fetchall() возвращает список кортежей (все результаты запроса). 
Можно использовать cursor.fetchone() для поштучного извлечения.
Основы SQL-запросов:

CREATE TABLE – создать новую таблицу (с указанием имен столбцов и их 
типов).

INSERT INTO ... VALUES ... – вставить новую запись (строку) в таблицу.

SELECT ... FROM ... WHERE ... – выбрать данные. Можно выбирать 
отдельные столбцы, все столбцы (SELECT *), добавлять условие отбора 
(WHERE), сортировать результат (ORDER BY), объединять таблицы (JOIN) 
и т.д.

UPDATE ... SET ... WHERE ... – обновить существующие записи.

DELETE FROM ... WHERE ... – удалить записи.
Пример выборки с условием:
python
Копировать

cursor.execute("SELECT name, age FROM users WHERE age > ?", (25,))
for name, age in cursor.fetchall():
    print(name, age)
Введение в ORM (SQLAlchemy)
ORM (Object-Relational Mapping) — это подход, при котором взаимодействие с 
БД происходит через объекты и классы, а не через прямые SQL-запросы. 
Библиотека SQLAlchemy является одним из самых популярных ORM для 
Python. Она позволяет определять модели (классы Python), соответствующие 
таблицам в БД, и работать с ними как с обычными объектами (создавать, 
выполнять запросы через методы, и т.д.), а под капотом SQLAlchemy будет 
генерировать SQL-запросы.
Основы SQLAlchemy (базово):

Установка: pip install sqlalchemy

Создание движка (engine) для соединения с БД.

Определение модели (класса) и сопоставление с таблицей (обычно с 
использованием декларативного стиля и Base).

Создание сессии для общения с БД.

Добавление/запрос/удаление объектов через сессию.
Пример минимальной модели и операции (для SQLite):
python
Копировать
from sqlalchemy import create_engine, Column, Integer, String
from sqlalchemy.orm import declarative_base, sessionmaker
engine = create_engine("sqlite:///example.db")  # соединение с той же SQLite 
базой
Base = declarative_base()
# Определяем модель (таблица users)

class User(Base):
    __tablename__ = "users"
    id = Column(Integer, primary_key=True)
    name = Column(String)
    age = Column(Integer)
# Создаем таблицы в БД (если не существуют)
Base.metadata.create_all(engine)
# Создаем сессию
Session = sessionmaker(bind=engine)
session = Session()
# Добавляем нового пользователя
new_user = User(name="Bob", age=25)
session.add(new_user)
session.commit()  # фиксируем транзакцию, новый пользователь записан в БД
# Запрашиваем всех пользователей из таблицы
users = session.query(User).all()
for user in users:
    print(user.id, user.name, user.age)
В этом примере:

create_engine("sqlite:///example.db") создает подключение (engine) к базе
данных SQLite.

declarative_base() дает базовый класс Base, от которого наследуем 
модель User.


Класс User имеет атрибуты, соответствующие столбцам таблицы: id, 
name, age. Мы указываем типы столбцов через Column(Integer) и т.д. 
__tablename__ задает имя таблицы.

Base.metadata.create_all(engine) создаст таблицу users (на основе 
описания модели) в базе, если ее еще нет.

sessionmaker создает фабрику сессий, через которые выполняются 
операции. session.add добавляет объект, но запись происходит только 
после session.commit().

session.query(User).all() возвращает список всех объектов User из БД.
ORM избавляет от необходимости писать SQL вручную, но требуются знания 
самой ORM и понимание, что происходит под капотом. Для простых проектов 
SQLite и прямых SQL-запросов через sqlite3 бывает достаточно, но для 
больших систем, особенно с различными СУБД (PostgreSQL, MySQL и др.), 
ORM упрощает работу.
11. Тестирование
Тестирование кода — неотъемлемая часть разработки. Оно помогает 
удостовериться, что код работает правильно, и упрощает поддержку (при 
изменениях тесты могут поймать регрессии). В Python есть встроенный 
модуль unittest и внешний популярный фреймворк pytest.
Модуль unittest
unittest – модуль из стандартной библиотеки, предлагающий 
функциональность для написания тестовых классов и методов. Основные 
концепции:

Создаете класс, наследуясь от unittest.TestCase.

Пишете методы, начинающиеся с test_, внутри которых вызываете 
проверки (assert).

Запускаете тесты через unittest runner (например, python -m unittest или
используя обнаружение тестов в IDE).
Пример теста с unittest:
python
Копировать
import unittest

def add(a, b):
    return a + b
class TestAddFunction(unittest.TestCase):
    def test_add_integers(self):
        self.assertEqual(add(2, 3), 5)
        self.assertEqual(add(-1, 1), 0)
    
    def test_add_strings(self):
        self.assertEqual(add("foo", "bar"), "foobar")
        self.assertIsInstance(add("foo", "bar"), str)
if __name__ == "__main__":
    unittest.main()
В этом примере:

Мы тестируем функцию add.

Метод assertEqual проверяет равенство ожидаемого и полученного 
результата.

Метод assertIsInstance проверяет тип результата.

Если запустить этот файл как сценарий, unittest.main() найдёт и запустит
все тесты (методы, начинающиеся на test).
unittest поддерживает множество видов проверок: assertTrue, assertFalse, 
assertIn, assertRaises (для проверки исключений) и др. Также можно писать 
методы setUp и tearDown (или их варианты с классами/модулями) для 
подготовки окружения к тесту и очистки после теста.
Фреймворк pytest (основы)
pytest — мощный и простой в использовании фреймворк для тестирования. 
Устанавливается через pip (pip install pytest). Основные преимущества pytest:


Не требует писать классы: тестовые функции достаточно называть с 
префиксом test_.

Простая и понятная обработка ассертов (стандартный оператор assert 
используется).

Богатая экосистема плагинов.
Пример теста с pytest (предположим, мы сохраняем этот код в 
test_example.py):
python
Копировать
# test_example.py
from mymodule import add  # допустим, функция add определена в 
mymodule.py
def test_add_integers():
    assert add(2, 3) == 5
    assert add(-1, 1) == 0
def test_add_strings():
    result = add("foo", "bar")
    assert result == "foobar"
    assert isinstance(result, str)
Чтобы запустить тесты, достаточно выполнить команду pytest в терминале 
(она найдёт файлы, начинающиеся с test_ и запустит функции внутри). Pytest 
покажет результат тестов, а при неудаче выведет подробное сообщение, в 
том числе значения, которые не совпали.
Pytest также поддерживает:

Фикстуры (fixtures) – специальные функции для подготовки 
данных/окружения, которые можно подключать к тестам.

Маркировки тестов (markers) – для группировки, пропуска, или 
ожидаемых провалов.


Параметризацию тестов – для запуска одного теста с разными 
наборами данных.
Оба инструмента (unittest и pytest) широко используются. Pytest часто 
предпочитают за лаконичность, но unittest хорош тем, что идет из коробки и 
близок по структуре к тестовым фреймворкам других языков.
12. Асинхронное программирование
По умолчанию, Python выполняет код последовательно. Асинхронное 
программирование позволяет запускать несколько операций 
"одновременно" (в рамках одного потока), переключаясь между ними, когда 
одна из них ожидает результата (например, загрузки данных из сети). В 
Python для этого используется механизм корутин вместе с ключевыми 
словами async и await и модулем asyncio.
Ключевые слова async и await
Начиная с Python 3.5 в языке появились ключевые слова:

async def — определяет асинхронную функцию (корутину).

await — используется внутри асинхронной функции для приостановки 
выполнения и ожидания результата от другой корутины или 
асинхронной операции.
Асинхронная функция при вызове не выполняется сразу, а возвращает 
объект корутины. Чтобы она действительно выполнилась, ее нужно 
запустить через цикл событий (event loop) — обычно с помощью asyncio.run 
или путем await внутри другой корутины.
Пример простой корутины:
python
Копировать
import asyncio
async def greeting(name):
    print(f"Hello, {name}!")
    await asyncio.sleep(1)  # асинхронная пауза на 1 секунду
    print(f"Goodbye, {name}!")

async def main():
    # запуск двух корутин "параллельно"
    task1 = asyncio.create_task(greeting("Alice"))
    task2 = asyncio.create_task(greeting("Bob"))
    # Ожидаем завершения обеих
    await task1
    await task2
asyncio.run(main())
В этом примере:

greeting – асинхронная функция, которая печатает приветствие, затем 
делает асинхронную паузу (не блокируя поток, а отдавая управление 
другим задачам на это время), и затем печатает прощание.

В main мы запускаем два задания почти одновременно с помощью 
asyncio.create_task. Они начнут выполняться конкурентно: пока первый 
greeting ждёт sleep, второй выполняется, и наоборот.

asyncio.run(main()) запускает цикл событий и выполняет main до 
завершения.
Важно: Асинхронность – не то же самое, что многопоточность. Здесь 
переключение задач происходит кооперативно, когда задачи сами указывают
где можно "уступить" поток (await). Асинхронность эффективна при вводе-
выводе (сеть, файлы), когда ожидание этих операций можно перекрыть 
работой других задач.
Библиотека asyncio (базовые примеры)
Модуль asyncio предоставляет:

Event loop (цикл событий) – управляет выполнением асинхронных 
задач.

Future и Task – низкоуровневые примитивы для представления 
обещаний результата.


Высокоуровневые API: asyncio.run, asyncio.create_task, корутины для 
задержек (asyncio.sleep), для сетевых операций и т.д.

Средства для синхронизации: Queues, Locks, Semaphores в 
асинхронном варианте.
Еще пример: параллельная загрузка данных (эмуляция с помощью sleep):
python
Копировать
import asyncio
import random
async def fetch_data(num):
    print(f"[{num}] Начало загрузки...")
    await asyncio.sleep(random.random()*2)  # эмулируем задержку 0-2 сек
    print(f"[{num}] Загрузка завершена")
    return f"data_{num}"
async def main():
    tasks = [asyncio.create_task(fetch_data(i)) for i in range(5)]
    results = await asyncio.gather(*tasks)  # ждем завершения всех задач и 
собираем результаты
    print("Results:", results)
asyncio.run(main())
В этом примере запускается 5 асинхронных задач fetch_data параллельно. 
Каждая "загружается" некоторое случайное время. В итоге они завершаются в
разное время, и asyncio.gather ждет их всех, возвращая список результатов. 
Это гораздо быстрее, чем запускать их последовательно (особенно если 
время ожидания большое), так как пока одна задача "спит", выполняются 
другие.

Асинхронное программирование имеет смысл использовать, когда у вас есть 
большое количество операций ввода-вывода, которые можно выполнять в 
перекрывающемся режиме. Для CPU-_intensive задач (многочисленные 
вычисления) асинхронность в одном потоке не поможет – там скорее 
понадобятся многопоточность или многопроцессность, но это отдельные 
темы.
13. Алгоритмы и структуры данных
Знание базовых алгоритмов и структур данных важно для понимания 
эффективности программ и для успешного прохождения технических 
интервью. Рассмотрим некоторые классические алгоритмы сортировки и 
поиска, а также структуры данных очереди, стека и деревья на 
концептуальном уровне.
Алгоритмы сортировки (пузырьковая, быстрая)
Сортировка пузырьком (Bubble Sort) – простой, но неэффективный 
алгоритм сортировки. Он многократно проходит по списку, сравнивая 
соседние элементы и меняя их местами, если порядок неправильный. 
Каждый проход "всплывает" наибольший из оставшихся элементов в конец 
списка, словно пузырек.
Сложность: O(n^2) в худшем и среднем случае.
Пример реализации пузырьковой сортировки:
python
Копировать
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]  # обмен элементов
    return arr
print(bubble_sort([5, 1, 4, 2, 8]))  

# Выведет: [1, 2, 4, 5, 8]
Bubble Sort легок для понимания, но для больших списков работает 
медленно.
Быстрая сортировка (Quick Sort) – гораздо более эффективный алгоритм 
(средняя сложность O(n log n), худшая – O(n^2), но на практике медленно 
случается). Quick Sort работает по принципу "разделяй и властвуй":
1. Выбирается опорный элемент (pivot).
2. Список делится на две части: элементы меньше опорного и элементы 
больше опорного (элементы равные pivot можно распределить любым 
образом).
3. Рекурсивно сортируются полученные подсписки, затем объединяются с 
опорным.
Пример быстрой сортировки (реализация через рекурсию):
python
Копировать
def quick_sort(arr):
    if len(arr) <= 1:
        return arr
    else:
        pivot = arr[len(arr)//2]  # выбираем средний элемент как опорный
        left = [x for x in arr if x < pivot]
        middle = [x for x in arr if x == pivot]
        right = [x for x in arr if x > pivot]
        return quick_sort(left) + middle + quick_sort(right)
print(quick_sort([5, 1, 4, 2, 8]))
# Возможный вывод: [1, 2, 4, 5, 8]
В реализации выше для простоты мы выбрали pivot как средний элемент 
списка и использовали генераторы списков для формирования left, middle, 

right. Эта версия не является in-place (она использует дополнительную память 
для списков), но демонстрирует идею.
Кроме пузырьковой и быстрой сортировки, существуют и другие алгоритмы: 
сортировка выбором, сортировка вставками (оба O(n^2)), сортировка 
слиянием (O(n log n) в любом случае, требует доп. память), пирамидальная 
сортировка (Heap Sort) и т.д. Python использует для sorted() и .sort() алгоритм
Timsort – гибридный алгоритм O(n log n), оптимизированный под реальные 
данные.
Алгоритмы поиска (линейный, бинарный)
Линейный поиск – простой алгоритм поиска элемента в списке: 
последовательно проверяем каждый элемент, сравнивая с искомым. 
Сложность O(n). В худшем случае приходится проверить весь список.
Пример линейного поиска:
python
Копировать
def linear_search(arr, target):
    for i, elem in enumerate(arr):
        if elem == target:
            return i  # возвращаем индекс найденного элемента
    return -1           # если не найден
print(linear_search([5, 1, 4, 2, 8], 4))  # Выведет: 2 (элемент 4 найден по индексу 
2)
print(linear_search([5, 1, 4, 2, 8], 7))  # Выведет: -1 (элемент 7 не найден)
Бинарный поиск – эффективный алгоритм поиска в отсортированном 
списке. Работает по принципу деления диапазона:
1. Смотрит на средний элемент списка.
2. Если он равен искомому – успех.
3. Если искомый меньше среднего – продолжает поиск в левой половине, 
если больше – в правой половине.

4. Повторяет, пока диапазон поиска не сократится до пустого (элемент не 
найден) или не будет найден искомый.
Сложность бинарного поиска: O(log n).
Пример бинарного поиска (итеративный):
python
Копировать
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1
    while low <= high:
        mid = (low + high) // 2
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            low = mid + 1
        else:
            high = mid - 1
    return -1
sorted_arr = [1, 2, 4, 5, 8]
print(binary_search(sorted_arr, 4))  # Выведет: 2
print(binary_search(sorted_arr, 7))  # Выведет: -1
Бинарный поиск требует отсортированных данных. В неотсортированном 
списке применяют линейный поиск или сначала сортируют (но сортировка 
дороже по времени, если делать каждый раз).
Очереди, стеки, деревья (краткий обзор)
Стек (Stack) – структура данных "последним пришел — первым вышел" (LIFO, 
Last-In First-Out). Представьте стопку тарелок: последняя поставленная сверху 
будет первой взята. Основные операции:


push (добавить элемент на вершину стека),

pop (убрать элемент с вершины стека).
Часто используется для отслеживания вызовов функций (стек вызовов), 
отмены операций (Ctrl+Z), обхода деревьев и т.д.
В Python список (list) можно использовать как стек: методы append и 
pop позволяют соответственно добавлять/удалять последние элементы.
Также модуль collections предлагает deque, который тоже может 
использоваться как стек (методы append и pop).
Очередь (Queue) – структура "первым пришел — первым вышел" (FIFO, First-
In First-Out). Как очередь в магазине: кто раньше стал, тот раньше обслужен. 
Основные операции:

enqueue (поставить в очередь),

dequeue (взять из очереди).
В Python для очередей часто используют collections.deque, так как у него
операции добавления слева и удаления слева эффективны (в списке 
удаление из начала списка неэффективно).
Пример:
python
Копировать
from collections import deque
queue = deque()
queue.append("Alice")   # enqueue
queue.append("Bob")
print(queue.popleft())  # dequeue: "Alice"
print(queue.popleft())  # dequeue: "Bob"
Деревья – иерархические структуры данных. Самый распространенный вид – 
дерево поиска или бинарное дерево поиска (BST), где каждый узел имеет 
не более двух детей: левого и правого. В бинарном дереве поиска для 
каждого узла выполняется свойство: все элементы в левом поддереве 
меньше (или равны) значения узла, а в правом поддереве больше (или 
равны). Это позволяет быстро искать элементы (средняя сложность O(log n), 
аналогично бинарному поиску, но уже в динамической структуре).

Обходы дерева бывают различные:

В глубину (DFS) – рекурсивно спускаемся вглубь (может быть order: in-
order, pre-order, post-order для бинарных деревьев).

В ширину (BFS) – по уровням, используя очередь.
Пример простого узла дерева и обхода в глубину (in-order) рекурсией:
python
Копировать
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
# Создадим простое дерево вручную:
root = Node(10)
root.left = Node(5)
root.right = Node(15)
root.left.right = Node(7)
# Рекурсивный in-order обход (левое поддерево -> узел -> правое поддерево)
def inorder(node):
    if node:
        inorder(node.left)
        print(node.value, end=" ")
        inorder(node.right)
inorder(root)  # Выведет: 5 7 10 15

В примере дерево:
markdown
Копировать
     10
    /  \
   5    15
    \
     7
Вывод in-order отсортирован: 5, 7, 10, 15.
Деревья – большая тема. В интервью на позицию Junior могут спросить 
базовые вещи: понимание что такое структура данных дерево, чем бинарное 
дерево поиска отличается от несортированного дерева, и может быть 
написать простой обход.
14. Работа с Git и командной строкой
Системы контроля версий – необходимый инструмент разработчика. Git – 
самая популярная система контроля версий, а командная строка часто 
используется для работы с Git и запуска различных утилит. Рассмотрим 
базовые команды Git и несколько полезных команд терминала.
Основные команды Git
Перед началом работы убедитесь, что Git установлен и настроено имя 
пользователя и почта:
arduino
Копировать
git config --global user.name "Your Name"
git config --global user.email "youremail@example.com"
Инициализация репозитория и базовые операции:

git init – инициализировать новый репозиторий в текущей папке 
(создаст скрытую папку .git).

git status – проверить статус (какие файлы изменены, добавлены, 
неотслеживаемы).


git add <file> – начать отслеживать файл или подготовить изменения 
для коммита (добавить в индекс). Можно git add . чтобы добавить все 
новые/измененные файлы.

git commit -m "сообщение" – зафиксировать изменения (создать 
коммит) с сообщением. Описательное сообщение обязательно, 
например: "Добавлен раздел ООП в руководство".

git log – просмотр истории коммитов. Клавиша Q для выхода из лога.

git diff – показать различия (незакоммиченные изменения в сравнении 
с последним коммитом).

git checkout -- <file> – отменить изменения в файле, вернув его к 
последнему коммиту (ОСТОРОЖНО: изменения пропадут).
Работа с удаленным репозиторием (например, GitHub):

git remote add origin <URL> – привязать удаленный репозиторий 
(обычно выполняется один раз после git init, URL можно скопировать с 
GitHub).

git push origin master – отправить изменения (коммиты) из локальной 
ветки master в удаленный репозиторий origin. (В современных GitHub 
вместо master часто main, нужно указать правильное имя ветки).

git pull origin master – получить изменения с удаленного репозитория и 
слить с текущей веткой (как правило, выполняется для синхронизации).

git clone <URL> – склонировать (скачать) удаленный репозиторий к себе 
(создаст папку с содержимым репозитория).
Работа с ветками Git
Ветки (branches) позволяют изолировать разработку разных функций или 
версий. Главная ветка обычно называется master или main. Новые ветки 
создаются для разработки фич, исправления багов и т.д., а потом сливаются 
(merge) обратно.
Основные команды:

git branch – список локальных веток (звездочкой отмечена текущая).

git branch <name> – создать новую ветку с именем <name> (оставаясь 
при этом на текущей ветке).


git checkout <name> – переключиться на ветку <name>. (С Git 2.23+ есть 
команда git switch <name> для переключения и git switch -c <name> для 
создания и переключения).

git checkout -b <name> – создать и сразу перейти на новую ветку.

git merge <name> – слить ветку <name> с текущей. Обычно: 
переключаетесь на основную ветку (например, main), потом git merge 
feature_branch. В результате коммиты из feature_branch вливаются в 
main.

git push origin <branch> – отправить свою ветку в удаленный 
репозиторий. Если ветка новая, может понадобиться --set-upstream 
origin <branch> при первом пуше.

git pull – когда находитесь в какой-то ветке, подтянуть изменения для 
нее с удаленного.
Разрешение конфликтов: Если изменения из разных веток затрагивают одни 
и те же строки, может возникнуть конфликт при слиянии. Git отметит 
конфликтующие места в файлах, вам надо их вручную исправить и после 
этого сделать git add <file> для помеченных конфликтов и git commit чтобы 
завершить слияние.
Командная строка (терминал) – основы
Работа с Git обычно происходит в терминале (особенно на серверах или в 
Docker-контейнерах). Полезно знать базовые команды оболочки (bash в 
Linux/Mac или PowerShell/cmd в Windows):

pwd (print working directory) – показать текущую директорию.

ls (list) – вывести список файлов и папок (Windows аналог dir).

cd <dir> (change directory) – перейти в указанную директорию.

mkdir <dir> – создать новую папку.

rm <file> – удалить файл, rm -r <dir> – рекурсивно удалить папку со всем 
содержимым.

cp <src> <dst> – копировать файл или папку (-r для папок).

mv <src> <dst> – переместить или переименовать файл/папку.

clear – очистить экран терминала (Windows: cls).

Для Windows PowerShell команды могут слегка отличаться (например, ls 
работает, но rm заменяется на Remove-Item). В любом случае, умение 
навигировать по файловой системе и запускать программы через терминал – 
важный навык. Например, чтобы запустить Python-скрипт, можно в 
терминале вызвать python myscript.py.
